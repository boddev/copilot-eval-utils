# Packaging assets

PNG assets referenced by `Package.appxmanifest`. Generated by
`packaging/msix/build-msix.ps1` (slice 33) when missing — the script
synthesises solid-colour placeholders sized to manifest requirements
so a fresh clone can still produce a structurally-valid MSIX.

Slice 34 / future branding will replace these placeholders with the
real EvalToolkit visual identity. The filenames are stable and must
match the manifest entries below.

| File                      | Dimensions | Manifest reference |
| ------------------------- | ---------- | ------------------ |
| `Square44x44Logo.png`     | 44×44      | `uap:VisualElements Square44x44Logo` |
| `Square150x150Logo.png`   | 150×150    | `uap:VisualElements Square150x150Logo` |
| `Wide310x150Logo.png`     | 310×150    | `uap:DefaultTile Wide310x150Logo` |
| `StoreLogo.png`           | 50×50      | `Properties Logo` |
| `SplashScreen.png`        | 620×300    | `uap:SplashScreen Image` |
| `evalset-logo.png`        | 44×44      | FTA `evaltoolkit-evalset` logo |
| `results-logo.png`        | 44×44      | FTA `evaltoolkit-results` logo |
| `report-logo.png`         | 44×44      | FTA `evaltoolkit-report` logo |

Scale-200 / scale-400 / target-size variants are recommended for shell
polish but are NOT required for manifest validation (GPT-5.5
slice-33 plan-review NB #2) — they will be added when the branding
ships.
